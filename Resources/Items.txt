# Items.txt
#
# Repository of all
# "Things that can be placed in character inventory &c"
#
# Each Item entry is of the following form:
#
# Item <item-name>
# {
#    variable-name    value
#     ...
# }
#
# Note: delimit <string> values with angle brackets <>
# Where variable-name/value are name/value pairs
# from the following list:
#
# Plural    string    how to properly refer to more than one of this thingy
# Type        string    One of the ITEM_IDX_ defines for item type
# Value    float    base cost to buy this item in a store
# Flags        string    comma-delimited list of additional ITEM_FLAG_ flags
# Color        string    RGBA value for this item's color
# AC        float    base amount this item changes the character's AC when equipped
# ACBonus        XdY    magical bonus to base AC
# Damage        XdY    base amount of damage this item inflicts when it hits something
# To-HitBonus        XdY    magical bonus to base to-hit chance
# To-DamBonus        XdY    magical bonus to base damage
# SpeedBonus   XdY    magical bonus to player speed
# Level        int        earliest dungeon level this item will appear at (range: 0 (town), 1( dung lvl 1) - 100 (dung lvl 100))
# AttackSpeed        float     how quickly one can attack with this item
# Weight       float     weight of the item in pounds
# Effect       string,XdY string = what it does, XdY = how much or for how long
# Charges      XdY    initial charges for wands/staves (rolled per instance)
#
#
# example item entry follows: e.g.
#Item <Long sword>
#{
#    Plural        <Long swords>
#    Type        <ITEM_IDX_SWORD>
#    Value        150.0
#    Level        1
#    Damage       <1d8>
#    Weight       6.0
#    AttackSpeed        5.0
#    Color        <200,200,200,255>
#}
# TODO: get all items sorted by type (and fix tests)

# Armor

#
# SPAWN WINDOW REDESIGN (TODO: implement bell-curve item placement in C++ engine)
#
# CURRENT BEHAVIOR: Level = hard floor. Item spawns in dungeon levels [Level, Level+10].
#
# DESIGN INTENT: Level should become the PEAK depth (center of a bell curve).
#   Items appear with peak probability at their Level, fade out above and below.
#   Out-of-depth items (shallower than Level) possible but rare.
#   Below-depth items (deeper than Level) possible but increasingly uncommon.
#   Some items (e.g. healing potions) remain findable at great depth with slow fade.
#
# Proposed new data fields (not yet in parser or engine):
#   LevelPeak   int    dungeon depth at which item is most common  (= current Level)
#   LevelSigma  float  spread of the bell curve (default ~10; consumables wider)
#   LevelFloor  int    hard minimum depth (0 = can trickle up to town)
#   LevelCeil   int    hard maximum depth (100 = never fades entirely)
#
# RESERVED LEVEL SPACE (items not yet implemented):
#   Level 60-70  Potion of Gain Str/Int/Wis/Dex/Con (x5)
#   Level 60     Potion of Restore Life Levels
#
