**JMoria**

I'm making this game that I've loved for years, I'll get around to putting in all the features.

*Commands*
hjklyubn - movement
HJKLYUBN - run until disturbed
o - open
c - close
T - tunnel
i - show inventory
e - show equipment
C - show stats
v - show visible monsters
V - show monster recall panel
( - show item recall panel
) - show map overview panel
w - wield an item
t - remove (take off) a piece of equipment
< - go upstairs
> - go downstairs
d - drop
* - choose target monster (choose target with .)
: - look (look around with movement keys, choose target with .)
. - rest one turn
R - rest until at full health, or until disturbed
q - quaff a potion
r - read a scroll
z - zap a wand (aimed — targets a specific tile or monster)
Z - use a staff (no targeting — affects the player or the surrounding area)
F - fill/fuel a light source
N - set character name
p - purchase something in a store
s - search
g - get/pickup
^c - exit game
^t - wizard teleport (Note: will turn on Wizard Mode, which prevents score being saved)
^f - wizard set flag (Note: needs Wizard Mode)
^i - wizard item (Note: needs Wizard Mode)
^d - wizard identify all inventory (Note: needs Wizard Mode)
^e - wizard give all wands and staves (Note: needs Wizard Mode)
^s - wizard summon (Note: needs Wizard Mode)
^w - exit wizard mode

*Items*
Players will automatically pick up items they walk over. Inventory is sorted by item type.
Wielded items are added to the player's equipment.
Removed items are added to the player's inventory.
Someday, Lady Teldra will be a sword in this game. You can count on it.
